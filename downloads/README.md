# Windows-комплект для TCL 55P737

Файл **TCL-Clean-Windows.zip** содержит подготовленный лаунчер CleanYourTV,
четыре плитки (VK Видео, YouTube, Happ, Кинопоиск), оригинальные инструменты
установки/восстановления и русскую инструкцию. AirPlay пока не включён.

Откройте [TCL-Clean-Windows.zip](TCL-Clean-Windows.zip) и нажмите **Download raw file**
(значок скачивания). Для закрытого репозитория предварительно войдите в GitHub.
Вариант: скачайте всю ветку через **Code → Download ZIP**, распакуйте её и найдите
архив в папке downloads. Затем полностью распакуйте сам TCL-Clean-Windows.zip.

Поместите папку TCL-Clean рядом с adb.exe на вашем компьютере Windows.
На компьютере нужны Google Platform-Tools и Python 3.10+; Android Studio не нужен.
Инструкция внутри архива: TCL-Clean/README-RU.md.

Комплект прошёл сборку, проверку подписи APK, Android Lint без ошибок,
308 JVM-тестов лаунчера и 29 локальных тестов инструментария. PowerShell-обёртка
проверена с имитацией ADB в PowerShell 7 на Linux; физический TCL и Windows
требуют проверки владельцем. 19 тестов upstream recovery прошли; из 12 проверок
защиты core-пакетов 10 прошли и 2 пропущены как Windows-specific.

Режим Launcher сначала сохраняет исходное состояние. После его завершения
проверьте Home, пульт, HDMI и четыре приложения до отдельного режима Clean.
Очистка отключает семь ненужных развлекательных приложений обратимо. Остальные
пакеты из первоначального списка скрываются с Home. Телеметрия TCL и другие VPN
пока сохранены для отдельного разбора; полного отключения всех фоновых служб нет.

Контрольная сумма самого архива находится в TCL-Clean-Windows.zip.sha256.
Для проверки в PowerShell:

```powershell
Get-FileHash .\TCL-Clean-Windows.zip -Algorithm SHA256
```
