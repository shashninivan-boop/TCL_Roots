# AirPlay для iPhone и Mac

Один дополнительный приёмник — [AirPlay Server от jqssun](https://github.com/jqssun/android-airplay-server),
который рекомендует CleanYourTV. Заявлены дублирование экрана, HLS-видео и звук
AAC/ALAC. Базовое требование Android API 23; в официальном APK v0.0.36 проверены
package io.github.jqssun.airplay, minSdk 23, TV launch activity, библиотеки
armeabi-v7a / arm64-v8a / x86_64. Это соответствует известной версии Android 11
телевизора; реальная совместимость декодеров и сети подтверждается на устройстве.

## Установка из Windows

Скачайте INSTALL-AIRPLAY.ps1 из этой папки через Download raw file и положите
рядом с adb.exe. Запускайте из той же папки platform-tools. Адрес в примере
замените адресом телевизора. Python, Android Studio и новый лаунчер не требуются.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\INSTALL-AIRPLAY.ps1 -TvHost 192.168.1.50 -AdbPath .\adb.exe -Install
```

Без -Install сценарий только скачивает и проверяет файл. Он скачивает APK
непосредственно из официального GitHub-релиза v0.0.36, проверяет SHA-256,
подключение и ABI, устанавливает только приёмник, открывает его и выставляет
имя TCL-AirPlay, автозапуск, фоновую работу и объявления mirroring/video/audio.
Понижение версии, автоматическое удаление, изменение Home и автоматическая выдача
специальных Android-разрешений не выполняются. При конфликте подписи обновления
сценарий останавливается; не удаляйте существующее приложение вслепую.

В источниках проекта проверены ключи настроек и SettingsReceiver, защищённый
разрешением DUMP. В файле официального релиза подпись проверена apksigner
(v1 и v2 прошли). Зафиксированные значения:

- SHA-256 APK: b8c7c595ed93f91562feedce92c27800f08f9c84df424f6ac2045e82324cf2a4.
- SHA-256 сертификата: 64ca1fa39ddf9e0e89c57d73fb681d2a5b35ae20f071771e2eb401b5032ef1a9.
- Исходники, изученная ревизия: a46cca0a6a1274e9e33c0e750f0f1c1eb1d881ea.

Проверка сертификата подтверждает корректность подписи скачанного релиза,
а не независимое совпадение ключа с Google Play. Контрольная сумма относится
именно к скачанному официальному релизу; другой APK потребует отдельной проверки.
APK не переупакован и не размещён в этом репозитории. Лицензия upstream — GPLv3;
исходники и официальный APK доступны у автора.

## Проверка

Телевизор, iPhone и Mac должны находиться в одной локальной сети без изоляции
гостевых клиентов. Приёмник должен быть запущен и показывать готовность.

1. iPhone: Пункт управления → Повтор экрана → TCL-AirPlay. Проверьте сначала
   домашний экран, затем видео со звуком из приложения Фото.
2. Mac: Пункт управления → Повтор экрана → TCL-AirPlay. Проверьте изображение,
   затем выберите TCL-AirPlay в выводе звука, если звук остался на Mac.
3. Для музыки выберите TCL-AirPlay в списке AirPlay-устройств аудиоплеера.
   Поддержка прямой передачи видео/музыки зависит также от приложения-источника.
4. После базового теста нажмите Home и повторите соединение. Для автоматического
   открытия изображения приёмнику может понадобиться Display over other apps:
   включите Launch on connect в его настройках и подтвердите запрос Android.
5. Перезагрузите ТВ и снова проверьте обнаружение. Включённый boot_auto_start
   не гарантирует, что ограничения фоновой работы конкретной прошивки TCL
   разрешат запуск; при сбое нужны текст ошибки и сведения со страницы приёмника.

DRM-защищённое видео (например, Apple TV) не поддерживается. Для такого контента
используйте штатные приложения телевизора. Не обещается 4K/HDR, отсутствие задержки
или работа любого приложения-источника. Если обнаружение пропало, проверьте,
не блокирует ли текущая конфигурация Happ локальную сеть/mDNS; не меняйте весь VPN
профиль вслепую. Для первичной проверки можно временно отключить туннель и сравнить.

Четыре прежних приложения остаются в доке. Новый приёмник может появиться в
нижнем списке приложений; отдельный AirPlay Status или другой магазин не нужен.
После проверки и настройки выключите USB debugging и проверьте закрытие ADB
прежним инструментом из TCL-Clean.
