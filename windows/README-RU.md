# TCL 55P737 — очистка и новый главный экран

Это комплект для Windows: лаунчер CleanYourTV, собранный из исходников ревизии
92fdd142566b8c55a5540a96fcdafb889141f644, и оригинальные инструменты автора.
На главном экране — VK Видео, YouTube, Happ и Кинопоиск, в таком порядке.
Другие приложения из присланного списка скрыты с экрана, но системные компоненты
не удалены. Настройки, сеть и входы доступны через кнопки лаунчера.
AirPlay добавим отдельно после проверки основного интерфейса.

## Подготовка

1. Нужны уже используемый `adb.exe` и Python 3.10+ с https://www.python.org/downloads/windows/.
   При установке Python включите Python Launcher (`py`) / добавление в PATH.
   Java, Android Studio и Android SDK на Windows не нужны: APK уже собран.
2. Полностью распакуйте архив. Поместите папку `TCL-Clean` рядом с вашим `adb.exe`
   в `platform-tools`. Не запускайте файлы прямо внутри ZIP.
3. Телевизор и компьютер должны оставаться в одной домашней сети, ADB — авторизован.
   Адрес в примерах `192.168.1.50` замените текущим адресом своего ТВ.
4. PowerShell откройте в папке `platform-tools`. Ниже это рабочий каталог всех команд.
   Сценарий при первом запуске установит зависимости Python только в локальное
   виртуальное окружение. Никаких дополнительных приложений на ТВ не устанавливается.

## Проверка без изменений интерфейса

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\TCL-Clean\RUN.ps1 -TvHost 192.168.1.50 -AdbPath .\adb.exe -Mode Inspect
```

Сохраняется папка `TCL-Clean\backup\<время>`: пакеты, отключённые пакеты,
свойства и настройки. Это не копия прошивки/данных приложений. Храните локально:
полные настройки и getprop могут содержать личные сведения; не публикуйте всю папку.
`advertising-candidates.txt` — отдельный отчёт о восьми кандидатах на дальнейшую
очистку; этот этап пока ничего из них не отключает.

## Новый интерфейс

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\TCL-Clean\RUN.ps1 -TvHost 192.168.1.50 -AdbPath .\adb.exe -Mode Launcher
```

Сценарий сверяет SHA-256 APK с `build.json`, сохраняет состояние **до смены Home**
оригинальным `recovery.py`, затем запускает оригинальный `build-and-install.ps1`
с `SKIP_BUILD=1`. Сохраняются его проверки и откат при неудачной передаче Home.
Дополнительные accessibility-сервисы не включаются, setupwraith и его Wi-Fi не трогаются.
Затем оригинальный `theme.ps1` применяет `profile\config.json`: четыре приложения
и скрытие остальных плиток. Это конфигурационный файл, не дополнительное приложение.
Отдельно проверяются default Home и возобновлённая MainActivity, сохраняется
`TCL-Clean\shots\launcher.png`.

Не продолжайте при ошибке установки или Home; пришлите текст ошибки. Не обходите
проверку подписи/запрет установки и не отключайте штатный Home вручную.

Нажмите **настоящую** кнопку Home на пульте. Проверьте четыре приложения, удержание
громкости, Settings, выбор HDMI и специальные кнопки пульта. Пришлите фото экрана.
Только после этой проверки переходите к очистке. Работа пульта, загрузка после
перезапуска и воспроизведение ещё требуют проверки на вашем телевизоре.

## Первый этап очистки

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\TCL-Clean\RUN.ps1 -TvHost 192.168.1.50 -AdbPath .\adb.exe -Mode Clean
```

Оригинальный `disable.ps1` отключит семь ненужных приложений из
`profile\apps-to-disable.txt`: Netflix, Prime Video, Stan, Rakuten TV,
YouTube Music, Google Play Games, Google TV/Play Movies. Приложения не удаляются.
Состояние проверяется по фактическому списку отключённых пакетов, а не только
по коду завершения команды. Сценарий ждёт 15 секунд для записи состояния Android.

Затем перезагрузите ТВ и проверьте Home, HDMI и все четыре приложения ещё раз.
Другие VPN пока сохранены, чтобы случайно не потерять рабочее подключение:
их отключение — после проверки Happ. Рекламные/телеметрические службы TCL
разбираются отдельным этапом по отчёту, а не по списку от другой модели.
Новые приложения после этой сборки могут появляться на Home; их можно скрыть
в настройках лаунчера или добавить в `hidden_apps` при обновлении конфигурации.

## Восстановление

Не удаляйте распакованную папку, список `profile\apps-to-disable.txt` и каталог
`%USERPROFILE%\.cleanyourtv` с оригинальными recovery-записями.
Используйте ту же учётную запись Windows и тот же адрес ТВ; при смене DHCP-адреса
сначала разберите перенос recovery-записи, не запускайте слепое восстановление.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\TCL-Clean\RUN.ps1 -TvHost 192.168.1.50 -AdbPath .\adb.exe -Mode Restore
```

Используется оригинальный `restore.ps1`: включаются ранее включённые пакеты,
возвращается записанный Home и настройки анимаций. Пакеты, уже отключённые до
очистки, не включаются автоматически. При отсутствующей recovery-записи сценарий
останавливается. Лаунчер остаётся установленным; данные приложений не удаляются.

Если установка прервалась и главный экран пропал, не выключайте отладку. Пока ADB
доступен, можно сначала вернуть штатный Home (компонент определяется на вашем ТВ):

```powershell
.\adb.exe -s 192.168.1.50:5555 shell pm enable --user 0 com.google.android.apps.tv.launcherx
.\adb.exe -s 192.168.1.50:5555 shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME com.google.android.apps.tv.launcherx
```

Пришлите выведенный компонент перед следующим действием; не угадывайте его имя.

## Завершение

После всех проверок выключите USB debugging и отзовите авторизации на телевизоре.
Проверка из той же сети при включённом ТВ:

```powershell
py -3 .\TCL-Clean\cleanyourtv\tools\adb-closed.py 192.168.1.50 5555
```

Только `closed` подтверждает отказ подключения на проверенном порту. Таймаут
не подтверждает закрытие. Повторите проверку после перезагрузки ТВ.

## Происхождение сборки

Полная версия исходников: https://github.com/Gathin23/cleanyourtv/tree/92fdd142566b8c55a5540a96fcdafb889141f644.
APK построен штатным Gradle release target, изменён только разрешённый
`launcher/app/src/main/res/values/config.xml`. Конфигурация приложена в `profile`.
Список скрытых пакетов применяется штатным механизмом темы, чтобы не раздувать APK.
В комплект входят исходники лаунчера, оригинальные скрипты и лицензии; сборочные
кеши, личные бэкапы, ключи подписи, APK других приложений не включены.
Штатная release-сборка проекта использует debug signing key; это не магазинная
подпись. Проверка apksigner подтверждает целостность подписанного APK, а SHA-256
фиксирует именно эту сборку. Будущие обновления требуют сохранения того же ключа
подписи у сборщика; приватный ключ в комплект не передаётся.
